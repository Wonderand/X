# M2 技术热点发现与候选审核设计

本阶段承接已确认的技术热点、多语言内容目标。所有实现、测试和开发数据直接位于 D:/project/X，复用 M1 的草稿、审核和发布流程。

## 范围

- 搜索规则：关键词、显式后端、1–7 天窗口、条数、可选定时执行。
- 受限执行器：调用用户配置的 yichen-skills 路由器和现有 AI HOT / AnySearch 脚本；不复制其源码、不执行路由器输出的任意命令。
- 运行记录：排队、执行、成功、部分成功、失败、覆盖、限制和已预留调用次数。
- 候选库：规范 URL 去重、保留各次命中与原始候选回执；完全相同的规范标题与日期自动分组，支持手动合并和拆分。
- 来源确认：可以粘贴已阅读正文；AnySearch 候选可明确请求一次受限原文读取，预览后再确认导入。搜索摘要永不自动当正文。
- 已确认来源可直接创建指定栏目和语言的草稿，后续生成与发布仍沿用人工审核。

## 外部路线

AI HOT 仅用于 AI 主题的近期发现，显式选择该后端；通用技术话题使用 AnySearch。未实现 X/Grok 原生搜索，不用公共网页路线冒充 X 原生结果。

先运行离线路由器并验证 ready、backend 和无需登录。只自行组装固定脚本的参数数组，shell=False。AI HOT 显式发送 keyword；AnySearch 保留查询文本，时间窗只在候选元数据上做筛选，未知日期标记未知，不宣称覆盖完整时间窗。

外部执行使用配置的 Python，隔离模式 -I、超时、输出上限和最小环境；不传递 XOPS 模型、发布和管理员凭据。外部 Runtime 路径只在 .env 配置，网页不能传命令或路径。脚本不存在时明确失败，不安装、不回退。

AnySearch 读取只接受该次搜索返回的完整候选，沿用原有签名与有效期约束。过期要求重新搜索。提取文本仅保留为待审核预览；选中链接的读取授权不会扩展到其他链接或媒体下载。

## 调度与限额

总调用上限配置于发现设置，初始为 0；每次搜索和明确请求的原文读取均在入队时原子预留一次，UTC 日统计，失败和未知结果不退回额度。定时默认关闭；开启规则要求明确后端与配置可用。停用后取消尚未开始的该规则任务；正在执行的调用可以结束但不自动继续下一阶段。

每次 tick 只补一个当前周期，不追补停机期间的历史周期。搜索任务中断后不自动重付费执行。调度错误与发布暂停分别管理，发现功能不能启用发布。

## 数据

新增 discovery_settings、search_rules、search_runs、discovery_topics、discovery_candidates、candidate_hits、discovery_calls、candidate_reads。

候选 URL 唯一；每次命中的完整原始候选保存在私有数据库，用于来源追踪与有界读取。网页/API 不返回私有回执。已导入来源记录保持不变，不被后续搜索覆盖。

分组采用保守的标题规范化和日期键，缺少日期按录入日分组。排序依据关键词匹配、已知时效与重复惩罚，展示为排序分而非客观真实性或热度。

## 页面与接口

新增 /discovery 规则及运行页面、/discovery/candidates 候选页、/discovery/candidates/{id} 正文确认页。复用原页面样式与登录/CSRF 校验，通过独立路由注册函数接入，不重构 M1 路由。

API 位于 /api/discovery，表单动作位于 /actions/discovery。导入必须显式 confirmed=true，正文非空；创建草稿必须指定语言和栏目。
